# Roadmap

## Milestone 0: Portable foundation

Status: included in the starter repository.

Goal: clone the repository on another computer, recreate the environment, run tests, and open the app.

## Milestone 1: Baseline economics

Goal: understand and validate the current state cost model.

Output: baseline notebook and documented assumptions.

## Milestone 2: AI enabled economics

Goal: compare the current workflow with an AI assisted workflow.

Output: cost per case, monthly value, annual value, and payback.

## Milestone 3: Scenario analysis

Goal: compare conservative, expected, and optimistic cases.

Output: scenario table and break even analysis.

## Milestone 4: Sensitivity analysis

Goal: identify which assumptions drive the business case.

Output: sensitivity charts and threshold findings.

## Milestone 5: Uncertainty simulation

Goal: stop treating uncertain assumptions as fixed values.

Output: Monte Carlo distribution of expected value and probability of positive ROI.

## Milestone 6: Real AI experiments

Goal: run a sample workload through one or more language models.

Output: actual task accuracy, tokens, latency, retries, and model cost.

## Milestone 7: Realized value

Goal: combine observed AI performance with adoption and workflow evidence.

Output: potential value versus realized value view.

## Milestone 8: Portfolio product

Goal: allow multiple AI use cases to be created, compared, saved, and reviewed.

Output: reusable decision platform for AI value assessment.

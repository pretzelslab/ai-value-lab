What you just learned

The one sentence

Money and customer harm move in the same direction when you change review, and in opposite directions when you change the control. So the control is the only thing that buys you both, and the only way to know how good it is, is to measure it.

The trap

At high control effectiveness the machine will happily tell you to remove human review entirely. It is arithmetically right and practically wrong.

It counts every error the same, so one wrong refund commitment weighs the same as fifty clumsy phrasings. It cannot see that a hundred errors in one week is a crisis while the same hundred over a year is survivable. It does not know review also trains agents and surfaces policy gaps. And it has no idea some review is contractually required.

When a model recommends something nobody would do, the model is missing a constraint. Use it as a floor, then apply the constraints it cannot see.

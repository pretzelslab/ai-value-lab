# AI Value Framework

## Core question

When does an AI enabled workflow create measurable economic value compared with the current way of working?

## Step 1: Define the current state

Capture volume, human effort, loaded labor cost, quality failures, rework, and other material operating costs.

## Step 2: Define the AI intervention

Identify which part of the workflow changes and what the AI actually does.
Avoid assuming that AI usage equals automation.

## Step 3: Define value drivers

The starter model uses:

1. AI adoption rate
2. Human time saved
3. Human review rate
4. AI service cost
5. AI rework rate
6. One time implementation cost

## Step 4: Compare economics

The first decision measures are:

1. Current monthly cost
2. AI enabled monthly cost
3. Cost per case
4. Monthly value
5. Annual value
6. Payback period

## Step 5: Test uncertainty

A credible AI business case should not rely on one point estimate.
Later versions should test ranges for adoption, accuracy, review effort, task volume, model cost, and time savings.

## Step 6: Replace assumptions with evidence

As experiments mature, estimated AI cost and quality values should be replaced with observed results from actual model runs.

## Working distinction

Potential value describes what the workflow could create under assumed performance and adoption.

Realized value describes what is actually achieved after model performance, user adoption, human review, process integration, and operating costs are observed.
